# Climate Co. — production site

Static website for Climate Co. in Breese, Illinois.

## Files
- `index.html`
- `styles.css`

## Deployment
Upload the files to the root of a GitHub repository and connect the repository to Cloudflare Pages.

## Notes
- No Node/npm, backend, database, API key, paid service, tracking, or build step.
- Phone links use `tel:`.
- Google Maps links open the business listing.
- The review section intentionally shows the Google rating/review count and a real customer quote rather than pretending to automatically sync reviews.
- Rating/count are a listing snapshot and should be checked before future edits.
- No services, prices, warranties, certifications, brands, guarantees, or other business claims were invented.
