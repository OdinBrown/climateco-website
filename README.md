# Climate Co. — zero-maintenance website

Static production site for Climate Co., 14160 Stolletown Rd, Breese, IL 62230.

Files:
- index.html
- styles.css

Deployment:
1. Extract the ZIP.
2. Put index.html and styles.css in the root of a GitHub repository.
3. Connect that repository to Cloudflare Pages.

Design/maintenance notes:
- No Node/npm, backend, database, API, build step, tracking, or paid dependency.
- No review count or displayed star rating that can become stale.
- The review section uses a real customer quote supplied from the Google listing and links to the live Google listing.
- Phone and Google Maps links are functional.
- Copy avoids temporary or unverified business claims.
- Responsive for desktop, tablet, and mobile.
